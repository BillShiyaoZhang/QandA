每个人都能一闪光的想到一些奇奇怪怪的问题。问题也许有趣、有启发性、值得科学探索，因此值得被记录。

现在有了超级强大的大模型，我们有了快速回答一些问题的工具，问题的答案可以快速被生成。对于问题的回答值得被记录。

不同的模型、不同的版本（或者有的时候是同一个模型在不同时间其实暗地里是不同的版本）对同一个问题的回答也许有不一样的地方。这些不同的答案值得被记录。

这些内容应该可以放到一个用户友好的交互式平台上让大家看到、使用。或许能依托 GitHub repo，用 GitHub page 部署？

---

也许问题的回答之后还会有追问。多个追问会形成分支，这也应该能管理、可视化等

---

不同问题、不同分支下的内容可能会实际上是互相有关联的，应该有一套机制分析、确定这种关联，并将它们连在一起？
