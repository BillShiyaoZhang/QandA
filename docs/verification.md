耗时是本机一次测量，不代表 GitHub runner 或所有浏览器的性能。容量文本为合成测试样本，不包含真实大附件或超长聊天。手机测试是 iPhone 13 尺寸的 Chromium 仿真，未等同真机 Safari 验收。

核心测试覆盖：历史版本与不可变记录、祖先闭包和主链环、归档继承、路径复制、未知元信息、撤回投影、依赖上下文隐藏、Markdown 清洗、来源幂等收据、审核目标重检、草稿冲突、事务恢复、误导文件路径、关联方向和驳回候选过滤。

浏览器检查覆盖：标签与历史页面、深层树导航及兄弟分支隔离、复制内容、答案比较、中文搜索、GitHub 表单参数、关系图元素及来处链接、窄屏溢出和运行错误、关闭 JavaScript 后沿普通链接阅读。投稿测试拦截 GitHub 请求，没有伪造公开投稿。

当前格式化器曾使条件表达式中的 HTML/SVG 标签消失。已恢复图形关键元素，增加 DOM 验收，并禁止格式化 `.astro` 文件；这是一个已知工具限制。

## 对照设计 §10.3 的复核

本地证据与外部验收分开记录。当前默认分支尚未包含投稿模板，因此 GitHub 表单的真实提交还依赖所有者批准合并与访问设置；不能用拦截请求的测试代替。

| 场景 | 已检查的本地证据 | 尚未完成 |
